# Asynchronous JavaScript Assignment

## Overview
This project explains and demonstrates asynchronous JavaScript using callbacks, promises, and async/await.

## Files
- `Task1_Callbacks.js` - Shows how callbacks work in asynchronous operations.
- `Task2_Promises.js` - Demonstrates Promise states and handling.
- `Task3_AsyncAwait.js` - Demonstrates async/await with promises.

## Execution Steps
1. Open the folder in a terminal.
2. Run each file using Node.js:
   ```bash
   node Task1_Callbacks.js
   node Task2_Promises.js
   node Task3_AsyncAwait.js
   ```

## Summary
- Callback: A function passed as an argument and executed later.
- Promise: Represents an eventual result with states Pending, Fulfilled, and Rejected.
- Async/Await: A cleaner syntax for working with promises.
- Advantage: Easier to read and write than nested callbacks.
